HAM LOG DATA — แพ็กเกจติดตั้งเป็นแอป (PWA)  v1.1
=================================================
ทำให้เปิดจากลิงก์เว็บ ติดตั้งเป็นแอปบน Windows / Mac ด้วย Chrome หรือ Edge
อัปเดตอัตโนมัติ และแชร์ให้เพื่อนด้วยลิงก์เดียว (ฟรี)

ไฟล์ในโฟลเดอร์นี้ ต้องอัปโหลดทั้งหมด (รวมโฟลเดอร์ icons และไฟล์ .nojekyll):
  index.html  manifest.webmanifest  sw.js  icons/  .nojekyll

--- ขั้นตอนโฮสต์บน GitHub Pages (ทำครั้งเดียว ~5 นาที) ---
1) สมัคร/เข้าสู่ระบบ github.com
2) กด New repository ตั้งชื่อ เช่น cw-console เลือก Public กด Create
3) กด "uploading an existing file" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป
   (ต้องลากโฟลเดอร์ icons ด้วย ไฟล์ .nojekyll ถ้าเครื่องซ่อนไว้ไม่ต้องกังวล ไม่จำเป็นมาก)
   กด Commit changes
4) ไปที่ Settings > Pages > Source เลือก "Deploy from a branch"
   Branch: main  โฟลเดอร์: / (root)  กด Save
5) รอ 1-2 นาที จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/cw-console/
6) เปิดลิงก์นั้นด้วย Chrome หรือ Edge จะเห็นไอคอนติดตั้งที่แถบที่อยู่
   (หรือเมนู ⋮ > บันทึกและแชร์ > ติดตั้ง / Edge: แอป > ติดตั้งเว็บไซต์นี้เป็นแอป)

--- อัปเดตเวอร์ชัน ---
เมื่อมีเวอร์ชันใหม่ ให้อัปโหลดไฟล์ทับใน repository เดิม (Add file > Upload files)
แอปที่ติดตั้งแล้วจะอัปเดตเองเมื่อเปิดครั้งถัดไป ถ้าเปิดค้างอยู่จะมีแถบ "มีเวอร์ชันใหม่" ให้กดโหลดใหม่

--- ข้อควรรู้ ---
* ข้อมูล (ตั้งค่า, Log) เก็บแยกตามที่อยู่เว็บ ถ้าเคยใช้ไฟล์ cw-console.html ในเครื่อง (หรือลิงก์เดิม)
  ให้กด "สำรองข้อมูล" ในของเดิม แล้ว "นำเข้า" ในลิงก์ใหม่
* Repository แบบ Public ทุกคนเห็นโค้ดได้ แต่ข้อมูลของผู้ใช้ (รหัส QRZ, Log) อยู่ในเครื่องผู้ใช้เอง ไม่ได้อยู่บน GitHub
* ตัวเชื่อม RBN (rbn-bridge.py) ยังต้องติดตั้ง Python (บน Mac รันด้วย python3 rbn-bridge.py) และรันในเครื่องเหมือนเดิม
  Chrome รุ่นใหม่อาจถามสิทธิ์ "เชื่อมต่อกับอุปกรณ์ในเครือข่ายภายใน" ให้กดอนุญาต
* ใช้ได้เฉพาะ Chrome / Edge (รองรับ Web Serial สำหรับคีย์ CW และ CI-V) ไม่รองรับ Safari / Firefox
* ออฟไลน์ใช้ได้ (ถอดรหัส, ส่งคีย์, Log) แต่ QRZ / RBN ต้องมีอินเทอร์เน็ต
* ใช้ทดสอบในเครื่องได้: เปิด Terminal ในโฟลเดอร์นี้ พิมพ์  python3 -m http.server 8000
  แล้วเปิด http://localhost:8000

* โหมด DIGITAL และ SATELLITE ปิดชั่วคราว (กำลังปรับปรุงและอัปเดต) ข้อมูล QSO เดิมยังอยู่ครบ
