# HLHf = HAM LOG HF — V1.4

โปรแกรมบันทึก Log และช่วยปฏิบัติการวิทยุสมัครเล่น สำหรับนักวิทยุขั้นกลาง-สูง (HF · CW · VOICE · SATELLITE) ทำงานบนเบราว์เซอร์ (Chrome / Edge) ติดตั้งเป็นแอปบน Windows และ Mac ได้ ไม่ต้องติดตั้งโปรแกรมอื่นเพิ่ม ข้อมูลทั้งหมดเก็บในเครื่องของผู้ใช้เอง ไม่ได้อยู่บน GitHub หรือเซิร์ฟเวอร์ใด ๆ

**เปิดใช้งาน:** https://e25ynh.github.io/HAM-LOG-HF/ · รุ่นเสียง VHF/UHF: [HLVhf = HAM LOG VHF](https://e25ynh.github.io/HAM-LOG-Vhf/)

## มีอะไรใหม่ใน V1.4
- **หน้า SATELLITE (รุ่น Ultimate)** ใช้งานได้แล้ว
  - รอบผ่านดาวเทียม 24 ชม. จากข้อมูลวงโคจร (TLE) ของ CelesTrak · ภาพท้องฟ้า Az / El · นับถอยหลัง AOS / LOS
  - **แผนที่** ตำแหน่งดาว เส้นทาง ±45 นาที พื้นที่ครอบคลุม (footprint) และสถานีเรา · ย่อ / ขยาย / ลากเลื่อนได้
  - **Doppler อัตโนมัติ** สั่ง IC-9700 โหมด Satellite ผ่าน CI-V (MAIN = รับ · SUB = ส่ง สลับย่านให้เอง และอ่านค่ากลับมาตรวจ) · U อยู่บน V อยู่ล่าง
  - **โรเตอร์ RC-2500** (GS-232B) ผ่าน USB / Bluetooth SPP / BLE · หมุนตามดาว หันรอจุดขึ้นก่อน 1 นาที จอดหลังดาวตก
  - ปุ่ม **อัตโนมัติ: ดาวที่ผ่านถัดไป** เลือกและติดตามดาวให้เอง
  - **บันทึก QSO แบบ Log4OM:** Band / Freq (ส่ง) · RX Band / RX Freq (รับ) ตามความถี่จริงตอนกดบันทึก · Propagation = Satellite · ชื่อดาว (รหัส LoTW เช่น SO-50, ARISS) · Satellite Mode (VU, UV …) · ส่งออก ADIF ครบช่อง
  - ดาวตั้งต้น: SO-50 · ISS · AO-91 · PO-101 · AO-123 · IO-86 · RS-44 · FO-29 (เพิ่ม / แก้ได้)
- **ตาราง QSO รวมที่ Dashboard:** หน้า CW และ SATELLITE ไม่มีตาราง Log แล้ว (หน้า VOICE ยังมี) · Dashboard › QSO ล่าสุด ปรับคอลัมน์ Country / QTH ให้ QTH กว้างที่สุด

## มีอะไรใหม่ใน V1.3
- **V1.3.1:** HF Conditions อ่านค่า K / A จาก NOAA รูปแบบใหม่ (เปลี่ยนเมื่อ มี.ค. 2569) ได้แล้ว · แสดงค่า SN · K = 0 แสดงเป็น 0
- **หน้า VOICE ครบเท่า HLVhf:** แผงพิมพ์ความถี่ (คลิกตัวเลขบนหน้าจอวิทยุ พิมพ์ `14.025` · `145.337.500` · `145625` ฯลฯ) ตั้ง MODE / DUP + ออฟเซ็ต / TONE ในแผงเดียว · ส่งไปวิทยุผ่าน CI-V · ความถี่ล่าสุด · ปุ่มลัด ↑↓
- **รีพีตเตอร์ไทย** เลือกแล้วตั้งครบในคลิกเดียว (แก้ไขรายการได้ที่ ตั้งค่า › รีพีตเตอร์) · **D-STAR** ช่อง UR / RPT1 / RPT2 บันทึกลง Log และ ADIF
- **MODE CW ในหน้า VOICE:** QSO CW ที่บันทึกจากหน้า VOICE อยู่ในตาราง VOICE ไม่ปนกับหน้า CW
- **Dashboard › QSO ล่าสุด** เป็นตารางเต็ม (ทุกโหมด) ปุ่มครบ: เลือก · ส่งออก ADIF / CSV · **ส่งออก ADIF ใหม่** · **อัปเดตชื่อ / QTH / Grid จาก QRZ** ย้อนหลัง · เอากราฟ 14 วันออก · ตาราง QSO หน้า VOICE ไม่มีแถวปุ่ม
- **ตัวถอดรหัส CW** ไม่เพี้ยนเป็น TTT / OM กลาง QSO เมื่อสัญญาณจางขึ้นลง (QSB) หรือมีเสียงรบกวน
- **Band Plan:** ส่วน CW ของ 70cm แก้เป็น 432.000–432.100 · เพิ่มย่าน 23cm (1240–1300 MHz)
- ฟังเสียงอัตโนมัติเมื่อเปิดหน้า VOICE · QR Code ลิงก์แอปใน ตั้งค่า › เกี่ยวกับ · หน้าตั้งค่าจัดกลุ่มใหม่ · ไฟล์ส่งออกชื่อ `hlhf-log-วันที่`

## มีอะไรใหม่ใน V1.2
- **อัปเดต 2026-10-31:** ตั้งชื่อ HLHf = HAM LOG HF · ช่องล็อกอิน QRZ / HamQTH พิมพ์ตัวเล็ก-ใหญ่ได้อิสระ · ปุ่มรูปตาดูรหัสผ่าน · ช่องผู้ใช้ HamQTH รับ Callsign หรือ Email
- โลโก้และไอคอนแอปใหม่ · แถบเมนูสีแยกตามโหมด · ปุ่มลิงก์ไป QRZ.com (เปิดหน้าของคู่สถานีให้ถ้ามี)
- Dashboard ดึงชื่อและที่อยู่จาก QRZ ของ Callsign เรา · ชื่อในตั้งค่าใช้ในมาโคร CW
- CW และ VOICE เก็บความถี่แยกกัน
- หน้า CW: พิมพ์แก้ข้อความมาโครได้ · ช่อง DECODE Rx-Tx รวมรับและส่งเรียงตามเวลา · ปุ่มกรองย่านของสถานี CQ · แผงถอดรหัสสูงขึ้น · Scope/Audio ไม่ทะลุกรอบ · ตาราง Log เห็น 10 QSO
- โหมดฝึก CW: บทเรียนแบบ Koch 39 บท (ต้องเรียนจบก่อนเปิดแบบฝึกอื่น) · คำอธิบายวิธีฝึกในหน้า · รุ่น Standard ใช้ได้เฉพาะโหมดฝึกหัด
- ตัวติดตั้งตัวเชื่อม RBN บน Windows ดาวน์โหลด Python ให้เองถ้ายังไม่มี
- **ฝึกส่ง (โหมดฝึก CW แบบส่ง) ปิดชั่วคราว** ระหว่างแก้ปัญหารับสัญญาณเสียงไม่เข้า ฝึกรับใช้ได้ตามปกติ
- รุ่น Plus ขึ้นไปเปิดหน้า CW ที่โหมดจริงจังทันที โหมดฝึกหัดเหลือเฉพาะรุ่น Standard

## มีอะไรใหม่ใน V1.1
- **วิทยุแยกอิสระรายโหมด**: โหมด CW กับ VOICE มีรายการวิทยุของตัวเอง (ตั้งค่า > ข้อมูลวิทยุ เลือกแท็บ CW หรือ VOICE) ไม่ผูกกันอีกต่อไป ตัดป๊อปอัพ "วิทยุ / เสียงใช้อยู่กับอีกโหมด" ออก เชื่อมต่อและฟังเสียงพร้อมกันได้
- **รุ่น Standard ฝึก CW ได้**: เข้าหน้า CW ได้เฉพาะโหมดฝึกหัด โหมดจริงจังต้องใช้รุ่น Plus ขึ้นไป
- ข้อมูลวิทยุเดิมที่เคยตั้งไว้ถูกคัดลอกให้ทั้งสองโหมดอัตโนมัติ ไฟล์สำรองเก่านำเข้าได้

## ทำอะไรได้บ้าง

### หน้า Dashboard
- สรุปจากสมุด Log: QSO ทั้งหมด, วันนี้ (UTC), 7 วันล่าสุด, จำนวนประเทศ / DXCC, สถานีที่ไม่ซ้ำ
- แถบสีย่านความถี่ และนาฬิกา UTC พร้อมเวลาเครื่อง
- **QSO ล่าสุด** ตารางเต็มทุกโหมด แก้ไขในช่องได้ · ส่งออก ADIF / CSV · ส่งออก ADIF ใหม่ · อัปเดตชื่อ / QTH / Grid จาก QRZ
- กราฟตามย่านความถี่ และโหมดที่ใช้บ่อย

### หน้า VOICE (FM / SSB / LSB / USB / CW / Digital Voice / D-STAR / VoIP)
- บันทึก QSO ตามย่านความถี่และโหมด พร้อมตาราง Log แบบแบ่งหน้า เลือกส่งออกได้
- **หน้าจอวิทยุจำลอง** แสดงโหมด ย่าน ความถี่ DUP / TONE กำลังส่ง (PWR) S-Meter และมาตรวัดวงกลม ALC / SWR / TEMP / VOLT / AMP พร้อม Scope ของวิทยุและ Audio Scope
- ต่อวิทยุผ่านพอร์ต USB อ่านความถี่ โหมด และมาตรวัดจริงได้
- **แผงพิมพ์ความถี่** (คลิกที่ตัวเลขความถี่): พิมพ์ได้หลายรูปแบบ ตั้ง MODE / DUP + ออฟเซ็ต / TONE · เลือกรีพีตเตอร์ · ต่อวิทยุอยู่จะสั่งวิทยุผ่าน CI-V
- **D-STAR:** ช่อง UR / RPT1 / RPT2 · **ฟังเสียงอัตโนมัติ** ตามอุปกรณ์เสียงที่เลือกในตั้งค่า
- ช่องความถี่แสดงขอบเขตย่านที่ใช้ได้ในไทย
- แท็บกราฟและแผนที่ของ QSO

### หน้า SATELLITE (รุ่น Ultimate)
- เลือกดาว หรือให้เลือกดาวที่ผ่านถัดไปเอง · ตารางรอบผ่าน 24 ชม. กรองมุมเงยขั้นต่ำได้
- ท้องฟ้า (Az / El / ระยะ / ความเร็ว) · แผนที่ย่อขยายได้ · แผง Doppler · แผงโรเตอร์ อยู่แถวเดียวกัน
- Doppler อัตโนมัติสำหรับ IC-9700 · ปรับละเอียดขารับ · ดาว Linear (RS-44, FO-29) เลื่อนจุดบนทรานสปอนเดอร์ได้
- โรเตอร์ RC-2500: หมุนตามดาว · ปุ่มหมุนเอง · จอด · หยุดฉุกเฉิน · ตั้งทิศเหนือ
- บันทึก QSO ดาวเทียมตามรูปแบบ Log4OM (ความถี่ส่ง / รับ แยกกัน · Satellite · Satellite Mode)

### หน้า CW
- ถอดรหัสมอร์สจากเสียงแบบเรียลไทม์ แสดง Scope และ Audio ข้อความที่ถอดได้แยกสีตามประเภท (Callsign, ชื่อ, QTH, RST, Prosign, Q-code)
- แบ่งแผงเป็น **ถอดรับ (RX)** และ **ถอดส่ง (TX)**
- จับ Callsign คู่สถานีจากเสียงที่ได้ทีละส่วน และดึงข้อมูลชื่อ / Grid จาก QRZ.com ได้ (ใส่บัญชี QRZ ของตัวเอง)
- มาโครข้อความตามแนว QSO มาตรฐาน ส่งเป็นรหัสมอร์สผ่านวิทยุ (กดปุ่มหรือคีย์ลัด) พร้อมเสียงโทนในเครื่อง บันทึก QSO อัตโนมัติเมื่อจบ
- แสดงสถานีที่กำลัง CQ จาก RBN (ต้องรันตัวเชื่อมในเครื่อง)
- **โหมดฝึกหัด** สำหรับรุ่น Standard (เปิดเป็นค่าเริ่มต้นเมื่อเข้าหน้า CW ไม่มีโหมดจริงจัง) · รุ่น Plus ขึ้นไปเปิดหน้า CW ที่โหมดจริงจังทันที ไม่มีโหมดฝึกหัด
  - ฝึก **รับ**: ฟังเสียงแล้วพิมพ์ด้วยคีย์บอร์ด
  - ฝึก **ส่ง**: ปิดชั่วคราว (รอทดสอบอะแดปเตอร์คีย์ USB)
  - แบบฝึก: ตัวอักษร A–Z / เลข 0–9 / สัญลักษณ์, Callsign (สุ่มทั่วโลกหรือระบุประเทศ), การสนทนา (มาตรฐานหรือสุ่ม)
  - ทุกแบบฝึกมีคะแนนและสถิติสะสม ตัวที่ตอบผิดบ่อยจะถูกสุ่มออกมาบ่อยขึ้น ปรับความเร็ว WPM, Farnsworth, ความถี่โทนได้

### การเชื่อมต่อวิทยุ
- Icom (CI-V) เช่น IC-7300, IC-9700, IC-705, Xiegu
- Yaesu และ Kenwood / Elecraft ผ่านคำสั่ง CAT แบบข้อความ
- โหมด CW กับ VOICE มีรายการวิทยุของตัวเอง **แยกกันอิสระ ไม่เกี่ยวข้องกัน** (เพิ่มได้หลายเครื่องต่อโหมด แยกการตั้งค่าต่อเครื่อง เชื่อมต่อพร้อมกันและฟังเสียงพร้อมกันได้)

### บันทึกและส่งต่อข้อมูล
- นำเข้า / ส่งออก **ADIF** (ใช้ต่อกับ Log4OM และโปรแกรม Log อื่นได้)
- สำรองและกู้คืนการตั้งค่า + Log เป็นไฟล์ .json
- ตารางเรียงคอลัมน์คล้าย Log4OM

### อื่น ๆ
- ติดตั้งเป็นแอปได้ (PWA) อัปเดตอัตโนมัติ ใช้งานออฟไลน์ได้บางส่วน
- ธีมสว่าง / มืด อัตโนมัติตามเวลา
- คู่มือในตัว 2 ภาษา (ไทย / English)

## รุ่นของโปรแกรม

| รุ่น | หน้าที่ใช้ได้ |
|---|---|
| Standard (เริ่มต้น) | VOICE + โหมดฝึกหัดของหน้า CW (ไม่มีโหมดจริงจัง) |
| Plus | VOICE + CW เต็มรูปแบบ |
| Pro | VOICE + CW + DIGITAL |
| Ultimate | VOICE + CW + DIGITAL + SATELLITE |

ปลดล็อกด้วยรหัสที่ผูกกับ Callsign ใส่ที่ ตั้งค่า > รุ่นของโปรแกรม ใน V1.4 หน้า SATELLITE ใช้ได้แล้ว (รุ่น Ultimate) · หน้า DIGITAL ยังปิดใช้งาน

## สิ่งที่ต้องมี
- Chrome หรือ Edge รุ่นใหม่ (ต้องรองรับ Web Serial เพื่อต่อวิทยุ) เปิดผ่านลิงก์ https
- สาย USB ของวิทยุ (ถ้าต้องการให้โปรแกรมอ่านความถี่ / สั่งคีย์)
- ตัวเชื่อม RBN (`rbn-bridge.py`) ต้องมี Python และรันในเครื่อง ใช้เฉพาะถ้าต้องการดูสถานี CQ

## ข้อจำกัดที่ควรรู้
- ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง ถ้าล้างข้อมูลเว็บไซต์หรือย้ายเครื่องต้องสำรอง / นำเข้า
- อัปโหลด Log ขึ้น QRZ / LoTW โดยตรงยังไม่ได้ ใช้วิธีส่งออก ADIF แล้วนำเข้า Log4OM หรือ TQSL
- Yaesu / Kenwood ไม่มีมาตรวัดกำลังส่ง (PWR) ในหน้าจอวิทยุ
- รูปแบบ Callsign ในแบบฝึกเป็นแบบโดยประมาณ ไม่ใช่รายชื่อจริง
- D-STAR: ช่อง UR / RPT1 / RPT2 ยังไม่ได้ส่งไปตั้งในวิทยุ และยังไม่มีรายชื่อรีเฟล็กเตอร์
- รายการรีพีตเตอร์ตั้งต้นมาจาก RepeaterBook ซึ่งยังไม่ได้ยืนยัน · ย่าน 160m / 80m / 6m / 70cm / 23cm ยังรอยืนยันกับประกาศ กสทช.
- SATELLITE: การสั่ง IC-9700 โหมด Satellite และโรเตอร์ RC-2500 แบบ BLE ทดสอบกับอุปกรณ์จำลอง ยังทดสอบกับเครื่องจริงได้จำกัด · ข้อมูลวงโคจรและแผนที่โลกต้องต่อเน็ตครั้งแรก (เก็บไว้ในเครื่องหลังจากนั้น)
- หน้า CW ไม่มีปุ่มเพิ่ม QSO ด้วยมือแล้ว (บันทึกอัตโนมัติเมื่อจบ QSO ด้วยมาโคร) · แก้ไข / ลบ / ส่งออกที่ Dashboard
- ทดสอบกับวิทยุจริงยังจำกัด เป็นส่วนใหญ่ทดสอบด้วยข้อมูลจำลอง ถ้าพบปัญหากับวิทยุรุ่นอื่นแจ้งได้
