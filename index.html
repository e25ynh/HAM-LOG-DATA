Scopeระดับสัญญาณที่โทน (เส้นประคือเกณฑ์)

QRZ.comค้นชื่อ / QTH / GRID ของคู่สถานี

การเชื่อมต่อวิทยุ

ใช้พอร์ต USB เดียวกันทั้งคีย์ (DTR/RTS) และอ่านความถี่ (CI-V) ค่า Baud และ Address ต้องตรงกับที่ตั้งในวิทยุ (IC-7300 ปกติ Address คือ 94) ถ้าเปลี่ยนค่า ให้ตัดการเชื่อมต่อแล้วต่อใหม่

เสียงเข้า ปุ่ม เริ่มฟัง / หยุด อยู่ที่หน้าหลัก

สถานีของเรา

ใช้เติมในข้อความมาโครและบันทึก Log

ย่านความถี่สมัครเล่นในไทย อ้างอิง

อ้างอิง RAST (2014) และ IARU R3 เท่านั้น ประกาศ กสทช. ปัจจุบันอาจต่างไป * = ยังไม่ยืนยัน สิทธิ์ใช้ขึ้นกับชั้นใบอนุญาต · แถวที่ไฮไลต์คือย่านของความถี่ปัจจุบัน ส่วนการกดเลือกย่าน (ป้ายสี) อยู่ที่หน้าหลัก

สำรองข้อมูล

การตั้งค่าและ Log เก็บอยู่ในเบราว์เซอร์เครื่องนี้ ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องจะหาย ควรสำรองเป็นระยะ ไฟล์สำรองไม่มีรหัสผ่าน QRZ/HamQTH

ธีมหน้าจอ

โหมดตามเวลาใช้นาฬิกาของเครื่อง และสลับให้เองโดยไม่ต้องรีเฟรช

เกี่ยวกับ

CW Console เวอร์ชัน
ถอดรหัส CW / ส่งมาโคร / Log QSO สำหรับนักวิทยุสมัครเล่น · ข้อมูลชื่อ-QTH-Grid จาก QRZ.com และ HamQTH.com (ใช้บัญชีของผู้ใช้เอง · HamQTH สมัครฟรีที่ hamqth.com มีข้อมูลเฉพาะคนที่เปิดเผยตำแหน่งไว้ · Data provided by HamQTH.com) · สปอตจาก Reverse Beacon Network · ตารางย่านไทยเป็นข้อมูลอ้างอิง ตรวจกับ กสทช. ก่อนใช้งานจริง · แจ้งปัญหาให้บอกเลขเวอร์ชันนี้

RBN สถานีที่กำลัง CQ (Reverse Beacon Network)

รายการสถานีอยู่ที่หน้าหลัก ใต้ป้ายย่าน เข้าระบบ RBN ด้วย Callsign ใน “สถานีของเรา” (RBN ไม่ใช้รหัสผ่าน)
เตือนเฉพาะสปอตสดหลังเชื่อมต่อ ไม่เตือนซ้ำสถานีเดิมในย่านเดิมภายใน 10 นาที แถบเตือนอยู่เหนือรายการ กดเพื่อตั้งความถี่ ถ้าฟังวิทยุผ่านไมค์ เสียงเตือนอาจเข้าไมค์ ให้เลือกแบบเงียบ
ดึงสปอตย้อนหลังและกริดของสถานีจากเว็บ RBN ผ่านตัวเชื่อม (ตามอายุสปอตที่เลือกข้างบน สูงสุด 24 ชม.) ดึงให้เองครั้งหนึ่งตอนเชื่อมต่อ
ติดตั้งตัวเชื่อม (ทำครั้งเดียว · Windows และ Mac)
เว็บ reversebeacon.net ไม่อนุญาตให้หน้าเว็บอื่นอ่านข้อมูลโดยตรง จึงใช้ “ตัวเชื่อม” เล็กๆ ที่รันบนเครื่องคุณเอง (รับเฉพาะ 127.0.0.1) อ่านฟีดสดของ RBN แล้วส่งมาที่แอป
  1. ติดตั้ง Python 3 (python.org ติ๊ก “Add python.exe to PATH”)
  2. กด แล้วดับเบิลคลิกไฟล์ install-rbn-bridge.bat (ถ้า Windows เตือน เลือก “More info” > “Run anyway”) ตอบ Y/N ว่าจะให้เปิดเองตอนเปิดเครื่องไหม
  3. กลับมาที่นี่ กด “เปิดตัวเชื่อม” (เบราว์เซอร์จะถามขอสิทธิ์ครั้งแรก) แล้วกด “เชื่อมต่อ”
ไม่อยากติดตั้ง: แล้วรัน python rbn-bridge.py เอง · ข้อมูลโดย reversebeacon.net
macOS (MacBook)
  1. เปิด Terminal พิมพ์ python3 --version ถ้ามีหน้าต่างให้ติดตั้ง Command Line Tools กดติดตั้ง (หรือติดตั้ง Python 3 จาก python.org)
  2. กด “ดาวน์โหลด rbn-bridge.py” ด้านบน ไฟล์จะอยู่ใน Downloads
  3. ใน Terminal พิมพ์ cd ~/Downloads && python3 "$(ls -t rbn-bridge*.py | head -1)" (คำสั่งนี้เลือกไฟล์ที่ดาวน์โหลดล่าสุดให้เอง กันรันไฟล์เก่าที่ชื่อซ้ำ) เปิดหน้าต่างนี้ค้างไว้ ถ้าเคยรันตัวเก่าอยู่ให้กด Ctrl+C ปิดก่อน (ถ้า macOS ถามเรื่อง network ให้กดอนุญาต)
  4. กลับมาที่แอป กด “เชื่อมต่อ” (ปุ่ม “เปิดตัวเชื่อม” และไฟล์ .bat ใช้ได้เฉพาะ Windows)
  5. ถ้า Python มาจาก python.org แล้วดึงย้อนหลังไม่ได้ ขึ้นข้อความ CERTIFICATE_VERIFY_FAILED ให้เปิด Applications > Python 3.x แล้วดับเบิลคลิก Install Certificates.command หนึ่งครั้ง
